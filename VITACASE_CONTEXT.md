# VitaCase Context

VitaCase is a Flutter mobile application in advanced beta / early production candidate state.

## Current Identity

- Privacy-first personal health organizer
- Local-first encrypted health vault
- Secure place for profiles, medical records, documents, reminders, appointments, emergency info, and preferences
- Design language: Serene Precision
- Inspired by Apple Health, 1Password, One Medical, and Notion Mobile

## Current Production Scope

VitaCase currently supports:

- Profile management
- Medical information
- Medication reminders
- Appointment scheduling
- Encrypted vault / document storage
- Notifications
- Security lock / PIN
- Biometric unlock
- Onboarding
- Emergency information
- Settings / preferences
- Adaptive ads

## Not Current Production Features

Do not describe VitaCase as an AI medical assistant.

The app does not yet fully support:

- AI assistant
- OCR summaries
- AI medical analysis
- Cloud sync
- Production-grade backup system

Future plans may include OCR extraction, AI summaries, and document intelligence. Treat them as future roadmap items only.

## UX Goals

VitaCase should feel:

- Calm
- Premium
- Trustworthy
- Secure
- Emotionally safe
- Minimal
- Healthcare-friendly

## Known Risk Areas

- Startup white screen risks
- Notification reliability issues
- Provider bleed
- Giant screens
- Incomplete localization
- Accessibility gaps
- Unfinished release features
- Vault privacy risks
- Prototype UX remnants
