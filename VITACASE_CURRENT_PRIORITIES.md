# VitaCase Current Priorities

VitaCase is an advanced beta / early production candidate. Prioritize release stability, privacy, trust, and polish over new feature expansion.

## Highest Priority Fixes

1. Startup lifecycle stabilization
2. Notification engine reliability
3. Secure vault preview system
4. Remove decrypted temp-file risks
5. Theme consistency
6. Localization completion
7. Profile/settings modularization
8. Accessibility pass
9. Performance optimization
10. Release polish

## Current Risk Areas

- Startup white screen risks
- Notification permission timing and recurrence reliability
- Provider bleed between screens/features
- Large screens that need modularization
- Incomplete localization
- Accessibility gaps
- Vault privacy risks
- Prototype UX remnants
- Inconsistent theme usage
- Unfinished release flows

## Default Decision Bias

- Stabilize before expanding.
- Preserve privacy before convenience.
- Prefer local-first behavior.
- Reduce app startup work.
- Keep sensitive flows interruption-free.
- Keep UI calm, premium, and minimal.
- Avoid adding AI/OCR claims before those systems exist.

## When Choosing Work Scope

Prefer tasks that:

- Reduce crash or white screen risk
- Improve reminder reliability
- Remove sensitive data exposure
- Simplify provider ownership
- Break giant screens into feature modules
- Improve localization and accessibility
- Make release behavior more predictable
